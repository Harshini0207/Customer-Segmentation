# Customer Segmentation Using Machine Learning
Project Overview

Customer Segmentation is a machine learning project that groups customers into different segments based on their purchasing behavior and demographic characteristics.
The project uses clustering algorithms to identify customer groups and understand their spending patterns. This helps businesses develop targeted marketing strategies and improve customer engagement.

Objectives
- Analyze customer demographic and spending patterns.
- Identify customer groups with similar characteristics.
- Apply unsupervised machine learning techniques.
- Visualize and interpret different customer segments.
- Compare K-Means and Agglomerative Clustering.

Dataset
Mall Customers Dataset
The dataset contains customer information with the following attributes:
- CustomerID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1-100)

Technologies Used
- Python
-Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

Machine Learning Algorithms
1. K-Means Clustering
K-Means is an unsupervised learning algorithm that divides customers into clusters based on similarities in their features.

2. Agglomerative Clustering
Agglomerative Clustering is a hierarchical clustering algorithm that starts with individual data points and progressively merges similar clusters.

Project Workflow
1. Data Collection
2. Data Loading and Exploration
3. Data Preprocessing
4. Exploratory Data Analysis (EDA)
5. Feature Selection
6. K-Means Clustering
7. Optimal Cluster Selection using the Elbow Method
8. Agglomerative Clustering
9. Cluster Visualization
10. Result Analysis

Results
The project identifies different customer segments based on their annual income and spending scores.
The clustering results help understand:
- High-income, high-spending customers.
- High-income, low-spending customers.
- Low-income customer groups.
- Customers with moderate spending behavior.
